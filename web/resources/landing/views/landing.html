Tracer

Lightweight, self-hosted log aggregation and alerting

OpenTelemetry is overkill for small projects. Tracer gets you error alerts and context—without the complexity.

{{if .IsAuthenticated}} Go to Dashboard {{else}} Get Started Sign In {{end}}

The Problem

  • • Complex setup with steep learning curves
  • • Expensive infrastructure and recurring costs
  • • Over-engineering for simple monitoring needs
  • • Vendor lock-in with hosted solutions

The Solution

  • • Single binary with SQLite storage
  • • Instant Telegram alerts for errors
  • • Trace ID grouping for request context
  • • Full control with self-hosting

Features

Collector Features

  • 📊 Multiple log formats (JSON, regex, journalctl)
  • 🔄 Auto-reconnect with WebSocket transport
  • 📈 System stats (CPU, RAM, disk) monitoring
  • 🎯 Smart sampling (100% errors, configurable for others)
  • 🚀 Startup pattern detection
  • 🔔 Alert thresholds for resources

Panel Features

  • 🔐 Session-based authentication
  • 👥 User management with role-based access
  • 📱 Telegram notifications per user/app
  • 🔍 Trace ID grouping for request context
  • 📊 Real-time analytics dashboard
  • 🗄️ Per-app SQLite databases

Deployment Options

Self-Hosted

(Recommended for full control)

  • • One-line install via curl script
  • • Full data ownership
  • • No recurring costs
  • • Systemd service management
  • • Configurable retention and sampling
  • • Collector-only mode for distributed setups
