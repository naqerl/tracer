LLM API Documentation

Access tracer-panel logs and analytics programmatically using markdown-formatted endpoints.

Authentication

All endpoints require authentication via API key.

Generate your API key in Settings → LLM API Keys section.

Using Your API Key

Use request header:

curl -H "X-API-Key: YOUR_KEY" "https://{{.BaseURL}}/panel.md"

Available Endpoints

Analytics

  • GET /panel.md

    Dashboard - Lists all collectors

  • GET /panel/collectors/{collector}.md

    Collector overview with system stats

  • GET /panel/collectors/{collector}/apps/{app}.md

    App analytics with statistics and grouped logs

💡 Tip: View the raw markdown version at /llm.md
